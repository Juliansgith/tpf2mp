# TPF2MP documentation

The repository root intentionally keeps only the project `README.md`. Maintained
guides and design documents live here; dated implementation evidence remains in
[`investigation/`](../investigation/README.md), and generated runtime evidence is
excluded from Git.

## Source-of-truth order

1. [Prototype status](PROTOTYPE_STATUS.md) defines what the current release
   implements and what it does not claim.
2. [Remaining work](REMAINING_FROM_BRIEF.md) is the current backlog.
3. [Architecture](ARCHITECTURE.md) defines module and authority boundaries.
4. [`investigation/`](../investigation/README.md) contains dated evidence and
   may describe older intermediate states.
5. [Release notes](release-notes/) are immutable historical records, not the
   current product specification.
