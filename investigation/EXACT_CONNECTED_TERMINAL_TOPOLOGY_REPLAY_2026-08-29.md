# Exact connected-terminal topology replay - 2026-08-29

## Relay failure

Relay session `mp-ab70273a64a19ffa` isolated three forms of the same stock
large bus-terminal click:

- a terminal on empty land completed;
- a terminal snapped to a town road rejected without changing either world;
- the same road-connected terminal over two houses removed both houses, then
  rejected and faulted as `native-rejection-mutated-prepared-core`.

The last canonical transaction, digest `d4c9d42f`, contained one modular
street terminal, two construction collateral roots, one removed town-road
edge, two new nodes, the private entrance edge, and both replacement halves of
the split town road. Both peers failed in Build 35924 while resolving node
shape attributes. The staged demolition was already irreversible, so the
strict session fault was correct.

## Why three adjacent fixes did not solve it

Earlier releases corrected real but incomplete layers: collateral staging,
typed construction conversion, opaque module metadata, and pre-demolition
resource validation. Their tests proved that the buildings retired and that a
construction root appeared. They did not prove that the final native command
contained the exact three-edge road/entrance graph.

The missed engine boundary is temporal. Adding a `ConstructionEntity` to a
Lua `SimpleProposal` does not immediately populate its street vectors. Build
35924 expands the construction resource only inside
`api.cmd.make.buildProposal`. Pre-factory code therefore saw an empty generated
graph. Replaying the captured graph there either lost the road split or
duplicated the construction's internally generated nodes and edges. This is
why apparently relevant fixes could pass synthetic tests while the connected
terminal remained broken.

## Correction

Construction replay now carries the exact typed topology beside the
materialized `ConstructionEntity` and reconciles it immediately after the
native command factory expands the resource, before the command is issued.

The reconciliation is deliberately structural:

1. The engine-generated graph must be a compatible prefix of the captured
   graph. Carrier, resource, endpoints, and object references are checked.
2. Generated entity IDs are retained, while their positions and tangents are
   replaced with the exact snapped click geometry.
3. Captured nodes and edges not generated by the construction resource are
   appended with fresh non-colliding temporary IDs. Every reference is
   remapped to the retained generated IDs.
4. Removal verification still checks the original road and collateral vector,
   and any mismatch rejects before command issue.

For this terminal, the native resource supplies two nodes and the internal
entrance edge. Reconciliation keeps those native IDs, moves the entrance node
to the captured road snap, and appends exactly the two town-road halves. A
normal modular rail station remains its native 13-node/12-edge graph with no
appended duplicate topology.

## Permanent regression contract

Offline coverage now proves both sides of the boundary:

- rail construction expansion remains 13 nodes and 12 edges;
- the connected street terminal becomes 2 nodes and exactly 3 edges;
- the generated entrance node adopts the captured snapped position;
- both replacement road halves reference that retained node;
- temporary IDs cannot collide with generated IDs;
- staged collateral replay retains the same exact topology; and
- source-size, syntax, cross-language, launcher, recovery, and packaging
  checks remain green.

The localhost validator also has a populated-save slice. It can load the exact
archived relay world and replay the exact captured transaction, instead of
using fixed coordinates intended for an empty disposable map.
